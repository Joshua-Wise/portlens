PortLens
Web Flasher

Flash PortLens firmware

PortLens is a pocket network analyzer. Plug in a board and click the button below to install the latest firmware directly from your browser.

  1. 1 Connect the board to this computer via USB.
  2. 2 Click Connect below, select your device, then select Install PortLens.
  3. 3 Wait for the flash to complete.
Requires Chrome or Edge (Web Serial API).
Install the CH340 driver if your board isn't detected.
