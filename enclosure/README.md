# Enclosure

3D-printable case for PortLens.

[`PortLens_Case.step`](PortLens_Case.step) holds two bodies, in millimetres:

| Body | Size |
|---|---|
| Case | 115.2 × 35.8 × 26.5 mm |
| End cap | 6.7 × 32.6 × 23.1 mm |

Bambu Studio, OrcaSlicer and PrusaSlicer open STEP files directly. For other slicers, convert the file to STL or 3MF first.
